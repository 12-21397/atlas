# 🎲 A 每日决策

一个轻量级的个人决策辅助工具，帮助你记录每日行动、分析投入重心，并在迷茫时随机抽取一个方向。

## ✨ 功能特性

- 📝 **今日记录** – 写下每天做了什么，支持历史日期回溯
- 🤖 **AI 分析** – 接入 DeepSeek API，自动识别你投入的项目和精力档位（⭐主力 / ◉涉及 / ○擦边），并给出精进建议
- 🎡 **决策转盘** – 不知道该做什么？转一下随机抽取一个项目，支持按分类筛选
- ✅ **待做备忘** – 简单的待办清单，支持勾选完成和清除
- 📅 **日历视图** – 查看有记录的日子，快速跳转
- 📊 **统计面板** – 项目累计投入、活跃天数、权重排行
- 🌙 **深色/浅色模式** – 一键切换
- 💾 **数据备份** – 支持导入/导出 JSON，换设备时可迁移

## 🛠️ 使用说明

### 基础使用
- **写记录**：在首页文本框写下当天做了什么，点击「保存」
- **AI 分析**：写完后点击「✦ 分析」，需要先在侧栏设置中填写 DeepSeek API Key
- **随机抽取**：点击转盘中央的「抽一个」，会随机显示一个项目
- **待办清单**：在顶部输入框添加今日待办，勾选或删除

### 项目管理
- 点击右上角「☰」打开管理面板
- 在「项目」标签页可以增删项目，并选择分类（想学/要做/娱乐/充电）
- 项目会显示今日是否投入（⭐ / ◉ / ○）

### 数据备份
- 点击顶部的「⬡」按钮，可以导出/导入 JSON 文件
- 换设备时先导出，新设备上导入即可

## 🔑 AI 功能说明

分析功能需要 DeepSeek API Key：
1. 访问 [DeepSeek 官网](https://platform.deepseek.com/) 注册并获取 API Key
2. 在侧栏「设置」中填入 API Key 和 Endpoint
3. 系统默认使用 `deepseek-chat` 模型

分析结果会展示：
- 直接投入的项目及精力档位
- 泛关联的项目（间接有益）
- 第二天可执行的小建议
